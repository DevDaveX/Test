01 · Eure Bibliotheken

Was könnt ihr zusammen spielen?

Deine beiden Accounts werden vereinigt und anschließend mit ihrem Account verglichen. Spiele werden anhand der Steam-App-ID abgeglichen.

Noch keine Bibliotheken geladen. Für den API-Abruf muss STEAM_API_KEY auf dem Server konfiguriert sein. Beispiele sind keine bestätigten Account-Spiele.

Profile & manueller Bibliothek-Import

Steam: Profil → Profil bearbeiten → Privatsphäre → Profil und Spieldetails öffentlich. Alternativ je Account Steam-XML, JSON (Steam-API-Antwort oder Liste mit appid/name) oder Zeilen im Format App-ID;Spielname importieren. Dateien bleiben lokal im Browser.

02 · Stimmung & Ausschlüsse

Eure Regeln für heute

Ein „Heute nicht“ ist ein hartes Veto. Unbekannter Preis sperrt jeden nötigen Kauf. Unbekannte Spielzeit fällt bei einem Zeitlimit heraus. Online-, lokaler und Remote-Play-Koop müssen zum geplanten Setup passen.

Deutsche EUR-Preise werden live abgefragt. Keine automatische Kaufaktion. Rabatte und Geschenkbeschränkungen vor dem Kauf im Store prüfen.

03 · Eure Auswahl

Worauf habt ihr Lust?

Eigenes Spiel / Eignung ergänzen

Besitz nur markieren, wenn bestätigt. „Zu zweit geeignet“ ist eure manuelle Bestätigung für euren Spielmodus. Store-Koop-Tags allein bestätigen das nicht.

Euer Gaming-Plan

Das Los entscheidet 💕

Wählt getrennt eure Wünsche. „Neutral“ bleibt im Lostopf; ein Veto schließt das Spiel für beide aus.

Euer nächster gemeinsamer Abend wartet.

Spiel-Warteschlange

So wird fair ausgelost

Zuerst greifen Besitz, Budget, Eignung, Zeit, Stimmung, Warteschlange und beide Vetos. Nur zulässige Spiele erhalten Lose. Aus diesen wird kryptografisch zufällig gewählt; Favoriten erhöhen auf Wunsch das Gewicht. Die Vorschau zeigt alle Ausschlussgründe. Es gibt keinen garantierten Gewinner, wenn kein Spiel passt.

Eure Daten

Wünsche, Bibliotheken und Warteschlange bleiben in diesem Browser gespeichert. Der Server fragt ausschließlich Steam ab. Keine Steam-Anmeldung im Browser. Für den automatischen Abruf benötigt der Server einen Steam-Web-API-Schlüssel.

Bei Beispieldaten sind Besitz, Preise und Eignung lediglich demonstriert. Sie ersetzen keinen Vergleich eurer Profile.
